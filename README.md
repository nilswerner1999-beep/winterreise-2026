# Winterreise 2026

Reise-App für London · Edinburgh · Glasgow, 24.11.–08.12.2026.

**App öffnen:** https://nilswerner1999-beep.github.io/winterreise-2026/

- Karte mit Route, Countdown zum nächsten Flug
- Tag für Tag: Flüge, Unterkünfte, Programm (Museen, Touren, Abende)
- Checkliste zum Abhaken (wird lokal im Browser gespeichert)
- Offline-fähig: Seite einmal öffnen, dann „Zum Startbildschirm hinzufügen“

Alles steckt in `index.html` (Daten in den Arrays `legs`, `stays`, `prog`, `todos`).
